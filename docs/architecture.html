Architecture Overview

Factory Inventory Management System

A full-stack demo for tracking inventory, orders, demand, backlog and spending across factory warehouses. A Vue 3 single-page app talks to a FastAPI service over REST. Data comes from JSON files held in memory. There is no database.

Data flow

What happens when a user changes a filter, for example selecting a warehouse on the Dashboard.

Filter change

FilterBar updates a shared ref in useFilters.

View reacts

The view's watch calls getCurrentFilters() and reloads.

api.js request

Drops 'all' values and sends the rest as query params.

FastAPI filters

List comprehensions narrow the in-memory data; dashboard totals are computed here.

Pydantic

response_model checks and serializes the response.

Render

Raw data goes into refs; computed properties derive KPIs, charts and tables.

Display-only concerns stay in the client. useI18n translates labels (English/Japanese), and utils/currency.js converts USD to JPY at a fixed rate of 150 when the locale is Japanese. The API always returns USD.

Filter system

There are four global filters. Their state is held at module level, so every view sees the same selection.

Time period
selectedPeriod → month

Accepts YYYY-MM or Q1-2025…Q4-2025. Matched as a substring of order_date.

Warehouse
selectedLocation → warehouse

Exact match. Applies to inventory and orders.

Category
selectedCategory → category

Case-insensitive match. Applies to inventory and orders.

Order status
selectedStatus → status

Case-insensitive match. Applies to orders only.

Inventory has no time dimension, so the month filter does not apply to it. Demand, backlog and spending endpoints ignore all filters.

Findings worth knowing

Issues found while mapping the code.

Gap

api.js calls /api/tasks (get, create, delete, toggle) and /api/purchase-orders, but main.py defines no such routes. These calls will return 404. CreatePurchaseOrderRequest is defined but not used by any route.

Unrouted

views/Backlog.vue exists but is not registered in main.js. Backlog data reaches users only through the Dashboard.

Inconsistent

Reports.vue calls axios directly with a hardcoded URL instead of going through api.js.

Hardcoded

Quarter mappings are fixed to 2025 in both QUARTER_MAP and the quarterly report logic. The JPY rate and API base URL are also hardcoded.

Ephemeral

All data lives in process memory. Any future write endpoint will lose its changes when the server restarts.
